# 未发布更新

## 椰子酱电商工作台 v1

- 复用 MxPage Electron 外壳，窗口标题、应用 ID 和用户数据目录改为「椰子酱电商工作台」。
- 窗口内共享口令登录。模型密钥与口令哈希只由主进程注入本机服务，页面不再提供 API Key，也不再写入渲染进程 localStorage。
- 首页改为聊天、做一张图、做一套图，以及译图和 Agent。隐藏单独小红书入口和监控热力图。
- 默认聊天模型 `gpt-6-luna`，默认可改 `gpt-6.2-sol` 与 `gpt-6.1-terra`。默认生图模型 `gpt-image-2.6-flare`，可改 `gpt-image-2.6-sunburst`。
- 译图补泰语、印尼语，请求尺寸和长图宽度跟随任务目标尺寸。
- 素材库三项默认：输入图自动入库，聊天图和生成结果不自动入库，任务使用副本。做一套图可以从素材库点选，并写入任务自己的副本。
- 桌面启动会写入默认模型服务和设置。密钥仍只留在主进程，不写入页面、localStorage 或设置表。
- 用户中心只保留头像和名称，不再渲染消耗热力图。默认显示名是「椰子酱」，资料文案不再写成只存在浏览器里。
- 侧栏不再单独放素材库。做一套图可从最近任务按原步骤接上，生图时列出每张状态，并可只导出选中图的 ZIP 或选中详情长图。做一张图可从任务接上，并有继续修改、版本列表和套用模板。
- 设置页不收集 API 密钥。单独的小红书图文流程页和作品筛选不再对使用人开放；小红书只留在组图平台下拉里。译图完成后不再停在「等待译图完成」。
- 头像和名称写入本机数据库，不再只放在浏览器 localStorage。直接打开 /library 会回到首页。任务计时里的旧图文类型不再标成小红书。



## 请求错误与图片恢复

- 区分模型请求失败/超时、结果查询失败和图片下载失败，按失败步骤显示恢复提示。
- 下载前保存已返回的图片地址；新增“仅恢复已有图片（查询 / 下载）”，只使用原任务或结果地址，结束后暂停，不触发生图及模型质检。
- 恢复模式拒绝同时授权计费重试；无法查询或下载时保留记录，不自动重新生成。旧异步任务编号继续支持查询恢复。

## 分镜数量与恢复

- 将逐页提示词预览、编辑和确认拆至独立 `/projects/[id]/prompts` 页面，待确认任务自动进入该步骤，确认生成后进入最终预览；保存草稿、刷新恢复及多标签页冲突保护继续有效。

- 分镜结构按用户自定义总张数约束，校验数量、重复及越界下标；完整乱序下标按页序排列。
- 新增明确计费确认的“仅重试视觉分镜”，保留已完成规划，支持旧任务保存了错误分镜的恢复。
- 重试后停在逐页提示词确认；已确认提示词或已发起图片请求的任务拒绝替换分镜。普通继续不会自动重试数量不合格的分镜。
- 使用隔离数据库和模拟模型验证自定义张数、无授权零重试、仅重做分镜及图片保护；未发起真实计费请求。
