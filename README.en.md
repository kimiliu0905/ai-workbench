# Yezijian Workbench

A local desktop app for OpenAI chat with image follow-ups and product-image composition. The full installation, configuration, development, and verification instructions are in the [Chinese README](README.md).

On Windows x64, run the `YezijianWorkbench-0.4.1-windows-x64.exe` installer. On Apple Silicon, unzip the macOS package and open the application. On first launch, open Settings and save an OpenAI API key.

Built on [MxPage](https://github.com/ziguishian/MxPage). Copyright and license are preserved in [LICENSE](LICENSE).
